# Self-Hosted configuration

The Compose file rejects empty production secrets. It does not contain fallback
credentials. Keep `.env` readable only by the deployment operator and do not
place it in a backup archive.

## Release and database

| Setting | Class | Purpose |
| --- | --- | --- |
| `REFKIT_IMAGE` | Required, operator | Exact semantic-version tag or digest from the matching release notes. A digest is preferred. |
| `REFKIT_VERSION` | Required, operator | Release version recorded in backups and checked during restore. It must match the image label. |
| `POSTGRES_IMAGE` | Generated default | Pinned PostgreSQL 17.10 multi-architecture image used by the supported topology and database tools. |
| `POSTGRES_DB` | Optional | Database name, default `refkit`. |
| `POSTGRES_USER` | Optional | Database owner, default `refkit`. |
| `POSTGRES_PASSWORD` | Required, secret | Password for the bundled database. Generate a URL-safe value such as 32 random hex bytes. |
| `DATABASE_URL` | Generated by Compose | Private connection from the application and migration job to the bundled database. |

PostgreSQL is attached only to the private `backend` network and has no host
port. Database data uses the `database` named volume. Do not copy a live volume
as a backup. Use the logical dump operation in [Operations](./operations.md).

## Application and recovery secrets

| Setting | Class | Purpose and loss behavior |
| --- | --- | --- |
| `REFKIT_EDITION` | Self-Hosted fixed value | Compose sets `self-hosted`. Do not change it. |
| `APP_URL` | Required | Exact public HTTPS origin with no path, for example `https://refkit.example.com`. It controls cookies, magic links, and stored upload URLs. |
| `REFKIT_HTTP_PORT` | Optional | Loopback port for the host proxy, default `3000`. |
| `BETTER_AUTH_SECRET` | Required, secret | Signs authentication state. Loss invalidates the trusted authentication configuration. |
| `PAYOUT_DETAILS_ENCRYPTION_KEY` | Required, critical secret | A base64-encoded 32-byte key used for encrypted payout and webhook data. Loss makes encrypted records unrecoverable. Never rotate it by replacing the value without a supported data migration. |
| `IP_HASH_SALT` | Required, secret | Salt for one-way client IP hashes. Preserve it for consistent hashing. |
| `SELF_HOSTED_SETUP_TOKEN` | Self-Hosted-only secret | One-time first-administrator bootstrap credential, minimum 32 characters. Keep it protected even after bootstrap. |
| `UPLOADS_DIR` | Self-Hosted fixed value | Compose sets `/var/lib/refkit/uploads`, backed by the durable `uploads` volume. |
| `WEBHOOK_ALLOW_PRIVATE_NETWORKS` | Optional | Default `false`. Set `true` only when an App intentionally sends an outgoing webhook to a private HTTPS address. |
| `ADMIN_EMAIL_ALLOWLIST` | Optional | Comma-separated internal Admin allowlist. Ordinary instance owners do not need it. |
| `ADMIN_ALERT_EMAILS` | Optional | Comma-separated operational alert recipients. |

Uploads are limited to 1 MB per App logo or user photo and to ten replacements
per entity per minute. RefKit retains only the active local file for each App
or user, but it does not impose a whole-volume quota. Monitor the upload volume
and backup destination. Only `/var/lib/refkit/uploads` is durable inside the application
container. The application root filesystem is read-only, its code and release
metadata are root-owned, and `/tmp` plus the Next.js runtime cache are
ephemeral in-memory filesystems.

## Email

Production Self-Hosted requires operator-owned delivery. `EMAIL_DELIVERY=log` is
rejected.

SMTP settings:

| Setting | Class | Purpose |
| --- | --- | --- |
| `EMAIL_DELIVERY` | Required | Set `smtp`. |
| `EMAIL_FROM_ADDRESS` | Required | Verified sender address used in all messages. |
| `SMTP_HOST` | Required for SMTP | SMTP hostname. |
| `SMTP_PORT` | Optional | Default `587`. |
| `SMTP_SECURE` | Optional | `true` for implicit TLS, normally port 465. Default `false` for STARTTLS. |
| `SMTP_USER`, `SMTP_PASSWORD` | Optional pair | If either is set, both are required. |

Resend settings:

| Setting | Class | Purpose |
| --- | --- | --- |
| `EMAIL_DELIVERY` | Required | Set `resend`. |
| `EMAIL_FROM_ADDRESS` | Required | Sender verified in the operator's Resend account. |
| `RESEND_API_KEY` | Required for Resend, secret | Operator-owned Resend API key. |

After startup, use the first-administrator flow to send a magic link and confirm
delivery before removing access to the setup token. After sign-in, open Admin
and select **Send test email** to run the authenticated delivery diagnostic.
Delivery errors are written to standard output without printing credentials.

If bootstrap creates the administrator but reports an email-delivery failure,
repair `.env`, restart the application, and request a new link from `/sign-in`.
Bootstrap stays closed. If the administrator address itself must change, use
the local recovery procedure in [Operations](./operations.md#administrator-email-recovery).

## Backup settings

| Setting | Class | Purpose |
| --- | --- | --- |
| `BACKUP_DIR` | Optional | Host destination, default `./backups` beside the Compose file. |
| `BACKUP_INTERVAL_SECONDS` | Optional | Scheduler interval, default 86400 seconds and minimum 300. |
| `BACKUP_RETENTION_DAYS` | Optional | Local archive retention, default 14. Set `0` to disable automatic deletion. |
| `BACKUP_MIN_FREE_MB` | Optional | Free space that must remain in addition to a conservative backup-size estimate, default 1024 MB. |

Local retention is not disaster recovery. Copy completed archives to encrypted,
off-server storage and monitor the `backup-scheduler` service.

## Image-provided values

The image, not the operator, sets `REFKIT_BUILD_VERSION`,
`REFKIT_SOURCE_REVISION`, `REFKIT_SOURCE_URL`, and
`REFKIT_RUNTIME_METADATA_FILE`. Readiness uses the bundled metadata to compare
the running source revision and expected migration with PostgreSQL. Do not
override these values.

Cloud-only variables such as `BLOB_READ_WRITE_TOKEN`, managed Stripe App keys,
and RefKit-operated service credentials are intentionally absent. Local test
variables such as `DEV_API_SECRET`, `DATABASE_URL_REMOTE`, and
`STRIPE_FIXTURE_MODE` do not belong in a production Self-Hosted deployment.
